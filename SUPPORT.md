# Support

Webhost Billing is community-supported software provided without an included SLA or
warranty.

## Where to ask

- Use [GitHub Issues](https://github.com/ebit101/webhost-billing/issues) for
  reproducible bugs and confirmed documentation gaps.
- Use a question issue for setup and usage questions until GitHub Discussions is
  enabled.
- Follow [`SECURITY.md`](SECURITY.md) for suspected vulnerabilities.

Before opening an issue, search existing reports and include the application version,
operating system, Node/pnpm versions, deployment method, relevant redacted logs, exact
steps, expected behavior, and actual behavior.

Never post passwords, API tokens, cookies, `.env` contents, customer information,
payment evidence, database dumps, private hostnames, or unredacted logs.

## Scope

Maintainers may help with the documented installation and project behavior. They are
not responsible for operating third-party payment providers, SMTP accounts, DNS,
cPanel/WHM, production infrastructure, taxes, legal compliance, or restoring an
installation that was not backed up.
