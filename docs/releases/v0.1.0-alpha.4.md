# Webhost Billing v0.1.0-alpha.4

This release adds customer cancellation of recurring hosting add-ons, a dedicated
administrator order details page with hosting approval, payment status on the
Orders list, and distinct administrator sidebar icons.

The add-on cancellation date starts at the first unbilled period. Any invoice
already issued keeps its original lines. Subsequent renewals exclude the add-on
while hosting continues on its billing cycle. Staff handle any work needed to
discontinue manually fulfilled extras.

Upgrade from alpha.3 with the dedicated SSH script. It verifies an encrypted
database backup, applies the additive add-on cancellation migration, and checks
all services. See the [changelog](../../CHANGELOG.md) and
[deployment handoff](../SSH_DEPLOYMENT_HANDOFF.md).
