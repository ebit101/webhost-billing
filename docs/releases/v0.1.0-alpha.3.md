# Webhost Billing v0.1.0-alpha.3

This release adds the Billing and Reports workspaces, hosting add-ons,
customer SSL indicators and hosting cancellation requests. It also adds
optional customer email two-step verification and audited read-only customer
support sessions.

See the [changelog](../../CHANGELOG.md) for the full list. The
[project handoff](../PROJECT_HANDOFF.md) explains deployment and verification.

When upgrading from alpha.2, apply pending migrations before starting the new
application. The dedicated SSH launcher verifies an encrypted database backup,
runs migrations, and waits for the application services to become healthy.
Use the recovery runbook for rollback. Database migrations are forward-only.
