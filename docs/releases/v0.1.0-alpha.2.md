# Webhost Billing v0.1.0-alpha.2

This alpha release adds typed server configuration, tabbed general settings,
public website and display preferences, versioned checkout terms, and a single
Domains workspace.

Apply the additive checkout terms migration before starting the application.
It adds a nullable acceptance snapshot to orders. Checkout terms start
disabled until configured. Virtualizor connection testing is gated by
`VIRTUALIZOR_API_ENABLED` and is disabled by default. VPS provisioning remains
outside this release.

Take and verify a database backup before upgrading. Use the deployment
rollback procedure for application images. Database migrations are forward-only.
